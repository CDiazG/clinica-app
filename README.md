# Gestión Clínica

Programa web de gestión para una consulta de oftalmología (historia clínica, recetas de gafas, informes, facturas, recibos y agenda).

Este repositorio **no contiene datos**. Los datos se guardan cifrados (AES-256, cifrado en el navegador) en el proyecto de Firebase de la clínica y solo se pueden leer tras iniciar sesión y con la clave de cifrado.
